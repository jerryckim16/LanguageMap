# Dictionary data

Generated by `scripts/build_dictionary.py`. Do not edit by hand; rebuild instead.

The content comes from [Wiktionary](https://www.wiktionary.org/) (English, Korean and Japanese
editions), extracted with [Wiktextract](https://github.com/tatuylonen/wiktextract) and downloaded from
[kaikki.org](https://kaikki.org/). Wiktionary text is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), so this derived data is too:
credit Wiktionary and share changes under the same license.

| Path | Contents |
|---|---|
| `meta.json` | counts, shard sizes, kyūjitai → shinjitai map |
| `ko/<n>.json`, `ja/<n>.json` | entries keyed by word, shard `n = djb2(word) % 256` |
| `m/<n>.json` | meanings (word senses), ids `512·n … 512·n+511`: `[english, pos, sense, [korean], ["japanese|reading"]]` |
| `en/<n>.json` | English word → meaning ids, shard `djb2(word) % 64` |
| `s/<key>.txt` | search index, one `type\tword\tkey\thint` line per key |

Entry fields: `r` romanization, `h` hanja, `k` kana readings, `p` parts of speech, `e` English glosses,
`d` definitions in the word's own language, `m` meaning ids, `j` / `o` direct translations
(Japanese / Korean), `c` words written with the same characters.
